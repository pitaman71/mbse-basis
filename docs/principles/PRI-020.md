# PRI-020: no constraint, any configuration

*Serves* [QUA-002: open-world models](../QUALITIES.md#QUA-002).

## Decided

- **The "open universe" design philosophy is interpreted by unions as "any".** As the user decided, in these words.
  Where a model offers alternatives at one place (the branches of a union; the
  grammar clauses a syntax node or a term takes at one place in a language's grammar), a value is accepted there if
  any alternative accepts it, and refused only where none does: alternatives widen what is accepted, as an absence of
  constraint accepts any configuration, and only a constraint narrows it ([PRI-021: refinement by
  constraint](../PRINCIPLES.md#PRI-021)).

  Example: Python's decorator grammar, recorded as two grammar clauses
  ([grammar clauses by version](../../proposals/GRAMMAR-CLAUSES.md)): "a decorator holds a dotted name, optionally
  called", allowed by Python 3.0 to 3.8, and "a decorator holds any term", allowed from 3.9 (PEP 614). `@app.route("/")`
  takes both, so it is accepted in every version, by whichever its target allows; `@buttons[0].clicked.connect` takes
  the second alone, so Python 3.8 refuses it. Read as "each", the first would be refused in every version.
