# FEA-028: one API surface for all data access

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-028).

Every access to data goes through one clean surface, the store's protocol `Visitors.OfStore`, so that any store serves any code alike.

## Capabilities

- [CAP-149: data accessed through the store protocol](../capabilities/CAP-149.md): met
- [CAP-126: schema objects read through the store protocol](../capabilities/CAP-126.md): not met
- [CAP-161: isolated stores, with no global registry](../capabilities/CAP-161.md): met
