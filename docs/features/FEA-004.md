# FEA-004: index site browser views

Index entries: [features/README.md](README.md#FEA-004), [capabilities/README.md](../capabilities/README.md). A capability without an ID is not in plan yet.

Lists of chips should default to auto scroll on overflow rather than
wrapping.

## Capabilities

- [CAP-009: schema browser](../capabilities/CAP-009.md) · schema browser with scrollable chip previews
- [CAP-010: object browser](../capabilities/CAP-010.md) · object browser with scrollable chip previews
- [CAP-011: relation browser](../capabilities/CAP-011.md) · relation browser with adjacency chip previews

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 36)** **Lists of chips scroll sideways** rather than wrap: every list of chips, a browser's (the Schemas and Objects tabs' sections, the Relations tab's
  entry rows) and the inspector's adjacency lists, is one row (`chipRow`), scrolled sideways where it overflows,
  snapping to its chips. A chip is at most 18rem wide, an adjacency's 24rem (it holds an entry's properties beside a
  pill), an entry row's 16rem; on a narrow screen each is at most 85% of the row, so that the next one shows and the row
  reads as scrollable.
