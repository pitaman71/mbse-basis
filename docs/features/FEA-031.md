# FEA-031: schemas as extensible data

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-031).

Schemas are data, reference objects of their meta-schemas in modules, that any store holding them extends.

## Capabilities

- [CAP-109: schemas as linked objects in modules](../capabilities/CAP-109.md): met
- [CAP-116: framework schemas extended, checked](../capabilities/CAP-116.md): met
- [CAP-117: extension adjacencies to any relation](../capabilities/CAP-117.md): not met
- [CAP-165: snapshots read by a store lacking their extensions](../capabilities/CAP-165.md): met
