# FEA-040: tenancy

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-040).

An app's instances keep each tenant's data as private as its tenancy says, from one private instance for a demo to many users who share only what they choose.
