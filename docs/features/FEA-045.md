# FEA-045: a Python, FastAPI and DynamoDB service stack

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-045). *Relates to* [FEA-003: no-code logical views](FEA-003.md).

Services run out of the box on Python and FastAPI, persisted in DynamoDB.

## Capabilities

- [CAP-012: logical view endpoints](../capabilities/CAP-012.md): to assess
- [CAP-013: an in-memory store journaled to DynamoDB](../capabilities/CAP-013.md): to assess

## Decided

- **Stacks as plugins**, as the user decided, for every stack feature: "FEA-001 and FEA-003 to me represent
  functionality as demoable on *any* acceptable stack. For versatility the framework provides out of the box support
  for a variety of popular stacks as plugins. So yes, they are related but also orthogonal." So each stack feature
  relates to [FEA-001: schema-driven UI](FEA-001.md), a UI stack, or to [FEA-003: no-code logical views](FEA-003.md), a
  service stack: this one, [FEA-051: a TypeScript service stack](FEA-051.md), and the UI stacks [FEA-046: a React,
  TypeScript and CSS-in-TS UI stack](FEA-046.md) and [FEA-050: a React Native UI stack](FEA-050.md) to [FEA-055: a Vue UI
  stack](FEA-055.md).
