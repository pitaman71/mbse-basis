# FEA-046: a React, TypeScript and CSS-in-TS UI stack

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). *Relates to* [FEA-001: schema-driven UI](FEA-001.md).

The UI runs out of the box on React and TypeScript, styled in CSS-in-TS. A stack the framework supports as a plugin, related to and orthogonal to [FEA-001: schema-driven UI](FEA-001.md), as the user decided ([FEA-045: a Python, FastAPI and DynamoDB service stack](FEA-045.md#decided)).
