# FEA-001: schema-driven UI

Index entries: [features/README.md](README.md#FEA-001), [capabilities/README.md](../capabilities/README.md). A capability without an ID is not in plan yet.

MVP components:

- `mbse-schemas` : semantic shapes for scalable data
- `mbse-rest` : transactional framework over REST endpoints
- `mbse-dynamodb` : adds persistence in DynamoDB
- `mbse-react` : adds react UI with multiple views

[`mbse-dynamodb/python3/mbse/Persistence/DynamoDB`](../../../mbse-dynamodb/python3/mbse/Persistence/DynamoDB) (`mbse.Persistence.DynamoDB`) : where the DynamoDB code lives, in the consolidated package space

## Capabilities

- [CAP-001: no-code index view](../capabilities/CAP-001.md) · no-code index view

## Not yet planned

### low-code custom views

Service + UI code should allow graceful extension by schema-aware
code provided by developers (e.g. FastAPI endpoints or React components).

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 14)** **Responsive layout**: on a screen 900px wide or more the inspector, once revealed, takes 2 of 5
  columns beside the browser (3 of 5); narrower, it covers the browser. Fonts scale from 14px to 18px with the width
  (`clamp`). Values are abbreviated to one line (40 characters in a chip, cut at a word, with an ellipsis and the full
  value as a tooltip; floats to 4 significant digits), and summaries to two lines; the inspector shows them in full.
- **(mbse-react 15)** **Auto scrolling**: each region scrolls on its own (the browser, each [CAP-009: schema
  browser](../capabilities/CAP-009.md) row, the inspector's body between its pinned label and actions); the chip of the
  object inspected scrolls into view; the inspector's body returns to the top on each navigation.
