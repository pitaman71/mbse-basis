# FEA-057: documentation organized by semantic role

*Confers* [QUA-010: every repository works alike](../QUALITIES.md#QUA-010), [QUA-001: AI and humans in the loop](../QUALITIES.md#QUA-001).

Every repository's documents, skills, notebooks and source comments each hold one kind of content, in one place, linked rather than restated, so that people and agents find the one source of each thing.

Internal: it serves the people and agents who work in the repositories, an engineering persona. Its rules are stated in [the basis](../README.md): the design spec, the doc spec, "What, why and how, each in one place", "A link is a link" and the rules for every document. Its capabilities are the documentation work those rules still leave to do.
