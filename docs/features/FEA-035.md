# FEA-035: clean modeling separation between value objects and reference objects

*Confers* [QUA-009: modeling provides clean separation of applications across constructs](../QUALITIES.md#QUA-009). Index entry: [features/README.md](README.md#FEA-035).

A model separates what it holds as values, owned and nested in containers, from what it links as reference objects, identified and related, so that each application of a construct is clean.

- [CAP-108: relations as scalable containers](../capabilities/CAP-108.md): met
