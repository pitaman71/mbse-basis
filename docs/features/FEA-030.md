# FEA-030: transactions

*Confers* [QUA-001: AI and humans in the loop](../QUALITIES.md#QUA-001). Index entry: [features/README.md](README.md#FEA-030).

A store changes only by transactions that commit all or nothing, journaled, snapshotted and replayed, each recorded with
who made it and when, so that a store's history is the trace of what changed. What a transaction names it names by
[FEA-026: deterministic object identity](FEA-026.md).

## Capabilities

- [CAP-124: writes all-or-nothing in transactions](../capabilities/CAP-124.md): met
- [CAP-125: imperative transaction scope](../capabilities/CAP-125.md): met
- [CAP-127: snapshots made of transactions](../capabilities/CAP-127.md): met
- [CAP-128: graphs sent as one-transaction documents](../capabilities/CAP-128.md): met
- [CAP-129: journals replayed by execution](../capabilities/CAP-129.md): met
- [CAP-134: transactions recorded with provenance](../capabilities/CAP-134.md): met
- [CAP-135: provenance records reproducible and attributable](../capabilities/CAP-135.md): not met
