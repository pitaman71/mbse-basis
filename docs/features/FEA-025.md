# FEA-025: schema-driven data

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). *Relates to* [PRI-018: no model needs code to read or write](../PRINCIPLES.md#PRI-018). Index entry: [features/README.md](README.md#FEA-025).

Data of any schema is built, read, written, compared and stored through generic machinery its schema drives; no model needs code of its own.

## Capabilities

- [CAP-107: one visitor protocol reads and writes data](../capabilities/CAP-107.md): met
- [CAP-108: containers of any index and element](../capabilities/CAP-108.md): met
- [CAP-109: schemas as linked objects in modules](../capabilities/CAP-109.md): met
- [CAP-110: a store's schemas read as one module](../capabilities/CAP-110.md): not met
- [CAP-111: equality and ordering defined by the schema](../capabilities/CAP-111.md): met
- [CAP-112: parameters declared by an installed module](../capabilities/CAP-112.md): met
- [CAP-113: parameters bound at their definitions](../capabilities/CAP-113.md): not met
- [CAP-114: bindings substituted and checked](../capabilities/CAP-114.md): not met
- [CAP-115: schemas defined by idempotent installs](../capabilities/CAP-115.md): met
- [CAP-116: framework schemas extended, checked](../capabilities/CAP-116.md): met
- [CAP-117: extension adjacencies to any relation](../capabilities/CAP-117.md): not met
- [CAP-147: links validated against their schemas](../capabilities/CAP-147.md): not met
