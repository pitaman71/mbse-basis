# FEA-025: serialization behavior conventions in schema

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-025).

Data of any schema is read and written, as values and containers, by conventions its schema declares, through one visitor protocol, so that no model needs code of its own to be serialized.

## Capabilities

- [CAP-107: one visitor protocol reads and writes data](../capabilities/CAP-107.md): met
- [CAP-108: containers of any index and element](../capabilities/CAP-108.md): met
