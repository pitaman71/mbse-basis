### store over DynamoDB

`Visitors.OfStore` implemented directly over DynamoDB, so that the store
need not fit in memory.

`mbse-rest` provides server-side and client-side adapter
components that translate query requests and responses, formatted 
as mutation expressions and frame streams. `mbse-dynamodb` 
implements `Visitors.OfStore` via a mutation expression executor 
that translates to and from dynamodb queries.

- UI proposes mutation query using mutation template
- `mbse-rest/typescript5/mbse/Services/Rest/Client.ts` translates mutation query into well-formed REST call(s)
- REST request is sent and received
- `mbse-rest/python3/mbse/Services/Rest/Service.py` unpacks REST payload into mutation expression form
- (persistence plugin) is called with mutation expression
- `mbse-dynamodb/python3/mbse/Persistence/DynamoDB/Plugin.py` query as mutation expression -> dynamo-db queries 
- Dynamodb receives query, processes, and responds
- dynamo-db response -> response as frame streams
- (persistence plugin) responds with stream of frames
- `mbse-rest/python3/mbse/Services/Rest/Service.py` serializes frame stream and returns as response data
