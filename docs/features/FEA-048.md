# FEA-048: date/time dialect

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-048). *Relates to* [FEA-007: property kinds](FEA-007.md).

Dates, times, durations and intervals are modeled in an ISO 8601 dialect, each kept as written, validated, and read as the value it encodes.

## Capabilities

- [CAP-212: dates, times, durations and intervals in ISO 8601](../capabilities/CAP-212.md): not met
