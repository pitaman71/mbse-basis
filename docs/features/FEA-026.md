# FEA-026: identity and transactions

*Confers* [QUA-001: AI and humans in the loop](../QUALITIES.md#QUA-001). Index entry: [features/README.md](README.md#FEA-026).

Objects are identified from the model, never at random, and a store changes only by transactions that commit all or nothing, so that the same model built twice, or in another language, gives the same identities and the same snapshots.
