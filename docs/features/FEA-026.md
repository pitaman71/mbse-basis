# FEA-026: deterministic object identity

*Confers* [QUA-001: AI and humans in the loop](../QUALITIES.md#QUA-001). Index entry: [features/README.md](README.md#FEA-026).

Objects are identified from the model, never at random, so that the same model built twice, or in another language,
gives the same identities. A store changes only by transactions: [FEA-030: transactions](FEA-030.md).
