# FEA-032: schema loading and wire alignment

*Confers* [QUA-006: the same in every language](../QUALITIES.md#QUA-006). Index entry: [features/README.md](README.md#FEA-032).

Schemas are loaded into a store by idempotent installs and read by name, so that every implementation holds and writes them alike.

## Capabilities

- [CAP-115: schemas defined by idempotent installs](../capabilities/CAP-115.md): met
- [CAP-110: a store's schemas read as one module](../capabilities/CAP-110.md): not met
- [CAP-156: the five basic scalars with boundless domains](../capabilities/CAP-156.md): met
- [CAP-158: values written as plain data, JSON and YAML](../capabilities/CAP-158.md): met
- [CAP-069: wire format shorthand (scalars)](../capabilities/CAP-069.md): met
- [CAP-070: wire format shorthand (containers)](../capabilities/CAP-070.md): met
- [CAP-071: unrestricted OfAny serializes with 1-level tag](../capabilities/CAP-071.md): met
- [CAP-170: unrestricted OfAny also accepts and roundtrips untagged plain data](../capabilities/CAP-170.md): not met
