# FEA-039: search, sort and filter in browser views

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-039).

Users search, sort and filter browser views, through logical views as the lens of every search.

## Capabilities

- [CAP-187: exact property match in the browser](../capabilities/CAP-187.md): not met
- [CAP-188: browser views paged](../capabilities/CAP-188.md): not met
- [CAP-189: keyword, semantic and hybrid search](../capabilities/CAP-189.md): not met

## Design

As the user wrote it:

> User can apply search, sort, and filter in browser views.
> Initially these will be in-browser executed and very
> simple. Keyword, semantic, and hybrid searches will evolve
> over time. Logical views are the lens through which
> searches operate.
