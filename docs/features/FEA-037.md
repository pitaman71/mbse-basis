# FEA-037: the framework built on its own protocols

*Confers* [QUA-007: one paradigm at every level of a system](../QUALITIES.md#QUA-007). Index entry: [features/README.md](README.md#FEA-037).

The framework's own code reads and writes its schemas and specs through the protocols and builders it offers every model, so that its maintainers keep one paradigm, not a special case beside it.

Internal: it serves the framework's maintainers, an engineering persona. Its capabilities are the framework's tech
debt where it reads or writes its own data outside those protocols.

## Capabilities

- [CAP-172: schema objects read through the visitor protocol](../capabilities/CAP-172.md): not met
- [CAP-173: spec items written through ordinary builders over a mutation sink](../capabilities/CAP-173.md): not met
