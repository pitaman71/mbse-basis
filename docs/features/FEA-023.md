# FEA-023: patterns over data

*Confers* [QUA-002: open-world models](../QUALITIES.md#QUA-002). Index entry: [features/README.md](README.md#FEA-023).

A pattern is a predicate: one constraint over a store's data, which is validated, queried, sampled from and generated
from alike. Built by mbse-patterns, over mbse-schemas' data and mbse-expressions' expressions.
