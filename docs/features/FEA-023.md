# FEA-023: patterns over data

*Confers* [QUA-002: open-world models](../QUALITIES.md#QUA-002).

A pattern is a predicate: one constraint over a store's data, which is validated, queried, sampled from and generated
from alike. Built by mbse-patterns, over mbse-schemas' data and mbse-expressions' expressions, until 0.9.1. As the
user decided (2026-11-05, [mbse-patterns' charter](https://github.com/pitaman71/mbse-patterns/blob/main/docs/proposals/rescope/README.md)), mbse-patterns 0.10.0 is started again
from scratch, for distributions, sampling, generators and characterizers; its predicates, queries and validators give
way to mbse-schemas' `OfPattern`, specs and executor ([CAP-150: predicates as data](../capabilities/CAP-150.md#decided)).
