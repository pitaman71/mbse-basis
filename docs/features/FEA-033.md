# FEA-033: model parameters

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008).

Models take parameters: a definition declares them, binds them, and has its bindings substituted and checked.

## Capabilities

- [CAP-112: parameters modeled as schema data](../capabilities/CAP-112.md): met
- [CAP-113: parameters bound at their definitions](../capabilities/CAP-113.md): not met
- [CAP-114: parameter bindings are substituted and checked](../capabilities/CAP-114.md): not met
- [CAP-163: parameters bound, applied and generated beyond mbse-schemas](../capabilities/CAP-163.md): not met
- [CAP-181: parameters wherever literals may appear](../capabilities/CAP-181.md): superseded by CAP-313
- [CAP-311: references stabilized](../capabilities/README.md#CAP-311): not met
- [CAP-312: a reference in place of any value](../capabilities/README.md#CAP-312): not met
- [CAP-313: parameter references bound and validated](../capabilities/README.md#CAP-313): not met

## Decided

- A parameter reference is universal: "a parameter reference, as a value object, may appear in any data structure in
  place of anything that has a schema", as the user decided. [The parameter references
  proposal](../../proposals/PARAMETER-REFERENCES.md#decided) records the user's rules for its validation, its
  simplification, its code generation and its wire form, and the capabilities that quantify it.
