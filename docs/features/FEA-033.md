# FEA-033: model parameters

*Confers* [QUA-008: usable without code](../QUALITIES.md#QUA-008). Index entry: [features/README.md](README.md#FEA-033).

Models take parameters: a definition declares them, binds them, and has its bindings substituted and checked.

## Capabilities

- [CAP-112: parameters declared by an installed module](../capabilities/CAP-112.md): met
- [CAP-113: parameters bound at their definitions](../capabilities/CAP-113.md): not met
- [CAP-114: bindings substituted and checked](../capabilities/CAP-114.md): not met
- [CAP-163: parameters bound, applied and generated beyond mbse-schemas](../capabilities/CAP-163.md): not met
