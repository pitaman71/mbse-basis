# CAP-006: chip view

*Implements* [FEA-003: no-code logical views](../features/FEA-003.md). Index entry:
[capabilities/README.md](README.md#CAP-006).

This is a medium-sized logical view of an object or a relation entry.

Given a `References.OfObject` or `References.OfEntry`, 
UI can obtain a logical view template, the response for which
comprises properties and adjacencies
for display in chip previews. The set of properties and 
adjacencies included in the response are intentionally
abbreviated.

For now the sensible default is the `label` and `summary` properties
([CAP-005: label and summary view](CAP-005.md)) and the first three other scalar properties the schema declares,
with no adjacencies.

## As built

mbse-rest serves this as the `chip` view kind: what its frames carry is in [FEA-003: no-code logical views](../features/FEA-003.md#view-kinds)'s view kinds, beside the other three.

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-rest 7)** **Chip**: "the first three other scalar properties" counts those the object holds, in the schema's
  order.
