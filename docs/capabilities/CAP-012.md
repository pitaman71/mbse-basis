# CAP-012: logical view endpoints

*Implements* [FEA-003: no-code logical views](../features/FEA-003.md). Index entry:
[capabilities/README.md](README.md#CAP-012).

Backend has one endpoint per logical view kind, each taking a
transaction expression (a template from [CAP-004: logical view templates](CAP-004.md), its symbols given).
Endpoints take no arguments: the mutation expression in the request's
body carries the query's bindings.
Its response is a stream of `References.OfFrame` whose `assigns` and
`entries` the service fills as the view kind defines.
