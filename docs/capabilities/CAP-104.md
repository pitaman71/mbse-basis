# CAP-104: typed values translated beyond C and SystemVerilog

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). Index entry: [capabilities/README.md](README.md#CAP-104).

## Design

The conversions and typed values have no counterpart yet in Python, MATLAB, Excel or LaTeX
([CAP-101: translation between dialects](CAP-101.md#translators), Translators); Basic translates them to C and
SystemVerilog.
