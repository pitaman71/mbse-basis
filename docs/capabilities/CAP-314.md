# CAP-314: parameters bound by the data objects their schema governs

*Implements* [FEA-033: model parameters](../features/FEA-033.md). *Supersedes* [CAP-113: parameters bound at their definitions](CAP-113.md). *Relates to*
[CAP-313: parameter references bound and validated](README.md#CAP-313), [CAP-312: a parameter reference in place of anything with a schema](CAP-312.md), [the parametrics proposal](../../proposals/PARAMETRICS.md#decided).

A schema may declare parameters, and a reference object that the schema governs may bind any of them, through
`Parametrics.BindsValue` and `BindsObject`, which link the object and the parameter. A parameter that the object leaves
unbound stays unbound. A schema binds none of its own parameters.

## Decided

As the user decided, besides the decisions the parametrics proposal records:

- **A schema's objects bind through an extension** ("yes Parametrics.extend"). `Parametrics.extend(schema)` gives a
  schema the adjacencies through which its objects bind its parameters, as `Provenance.extend` gives a schema its
  records' adjacencies.
- **Value objects bind differently** ("Value objects bind differently. For expression terms, a parameter binding term
  can be a kind of term."). A value object is never linked, so that `BindsValue` and `BindsObject` bind reference
  objects alone. In mbse-expressions, a term binds parameters as a kind of term of its own.
- **The bound object's link is named `object`** ("yes as you suggest"). `BindsValue` links `object` and `param`, its
  value the property `value`; `BindsObject` links `object`, `param` and `obj_ref`.

## Design

- A binding names a parameter that the bound object's schema declares, and a binding of any other parameter is
  refused.
- Whether a binding's value, or its object, is of the schema that its parameter is for is validated by
  [CAP-313: parameter references bound and validated](README.md#CAP-313).

## Open questions

- **Value objects outside expressions.** How does a value object that is not an expression term, such as a matrix
  held as a value, bind parameters?
