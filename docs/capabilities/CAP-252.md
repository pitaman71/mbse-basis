# CAP-252: new repositories scaffolded in the conventions

*Implements* [FEA-057: documentation organized by semantic role](../features/FEA-057.md). *Relates to* [PRI-041: a new repository starts in the conventions](../PRINCIPLES.md#PRI-041).

## As built: mbse-basis

`python3 scripts/polyrepo.py new <dir> --package <Area.Name> [--npm <name>]`, run from mbse-basis, creates `<dir>`
beside mbse-basis from the templates in `scripts/templates/repo/`, each named for the file it makes with `.tmpl`
added, so that no tool reads a template as a document or a source file. It fills each template's `{{REPO}}`,
`{{PACKAGE}}`, `{{PACKAGE_PATH}}`, `{{NPM}}` and `{{BASIS_COMMIT}}`, in its text and its path, by string replacement,
and refuses one it does not know. It then copies the skill into both packages with the new `skills/sync.sh`, writes
the navigation lines with `update_doc_links.py`, runs `git init` and stages every file, and prints the next steps.
It refuses a `<dir>` that exists, one not beside mbse-basis, and names not in the forms of
[PRI-030: one package layout](../PRINCIPLES.md#PRI-030). [The tools' README](../../scripts/README.md#a-new-repository) lists the starting set.

Checked by `scripts/test_scaffold.py`: a scaffold beside a copy of mbse-basis has every file, staged, every placeholder
filled, `update_link_forms.py`, `update_item_titles.py` and `update_doc_titles.py --check` clean, and its Python
notebooks' cases passing; and a real scaffold, mbse-example, passes `uv run pytest` (with coverage at 100%) and
`npm test` (and `npm run coverage`).

## Decided

As the user decided (2026-11-05):

- The scaffold is `python3 scripts/polyrepo.py new <dir> --package <Area.Name> [--npm <name>]`. It creates a new
  repository directory, beside the others, from templates kept in mbse-basis. Names are filled in with simple
  `{{placeholders}}`, string replacement only, standard library only.
- The templates are starting points, filled in once; they are not copies kept in sync, so
  [PRI-016: guidance written once](../PRINCIPLES.md#PRI-016) is not broken.
- The starting set: `AGENTS.md` (what the repository is, a sentence to fill; a start-here table; the "Read before any
  work" section and the `mbse:` resolution rule, each verbatim; a Commands block), `CLAUDE.md` (`@AGENTS.md`),
  `README.md` (opening with why, to fill, with navigation lines), `MBSE.md` as mbse-diagrams has it, `siblings.json`,
  a minimal Python package (`pyproject.toml` with uv, the package directory, a `tests/` notebook directory,
  `tutorials/README.md`) and a minimal TypeScript one (`package.json`, `tsconfig.json`, `tests/`,
  `tutorials/README.md`), shaped as mbse-diagrams' are; `skills/<repo>/SKILL.md` as one source, with a placeholder
  practice and an opt-out on its intro sections, `skills/sync.sh` and the packaged copies; the skill-test notebook in
  both languages, with SKL-01, SKL-03 and SKL-04, from mbse-patterns' `05_Skill`, generalized by placeholders;
  `docs/EQUIVALENCE.md`, with its "Cases in one language only" section; and the test plans.
- After writing, the scaffold runs `update_doc_links.py` on the new repository and prints next steps. It refuses an
  existing directory.

## Decided by an agent, for review

- **mbse-basis alone is pinned** (mbse-basis, branch CAP-252), not mbse-schemas behind a flag: a sibling's dependency is three
  edits (`siblings.json`, `pyproject.toml`, `package.json`) that the next steps list, then `polyrepo.py pin`; a flag
  would need the sibling checked out to read its version, and its own template variants.
- **The placeholder practice links PKG-01** (mbse-basis, branch CAP-252), a case the scaffold writes in both languages (both
  packages carry one version, and the package loads), so that SKL-03, which requires a linked case, and SKL-04 pass
  without an opt-out on the practice. The text a person fills in is marked `TO FILL`, never a `{{placeholder}}`.
- **The SKL notebook is mbse-schemas' `15_Skill`** (mbse-basis, branch CAP-252), the same cases as mbse-patterns' `05_Skill`
  plus SKL-03's reading of `docs/EQUIVALENCE.md`'s "Cases in one language only", which the starting set has; it is
  `02_Skill`, after `01_Package`, and checks `AGENTS.md` and the skill (no `llms.txt`).
- **`git init` and `git add`, no commit** (mbse-basis, branch CAP-252): the link tools read only the files git tracks, and the
  first commit, with the lock files `uv sync` and `npm install` write, is the person's.
- **The new repository's name is `mbse-` and lowercase words**, and `--npm` defaults to `@mbse/` and the name without
  `mbse-`, as [PRI-030: one package layout](../PRINCIPLES.md#PRI-030) has it (mbse-basis, branch CAP-252).
