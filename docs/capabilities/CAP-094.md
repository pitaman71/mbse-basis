# CAP-094: every construct of Verilog's and SystemVerilog's standards

*Implements* [FEA-008: expressive program models](../features/FEA-008.md).

## As built: mbse-programs

The kinds hold IEEE 1800's grammar ([CAP-063: complete kinds for Verilog and SystemVerilog](CAP-063.md)), and slang reads every text as
IEEE 1800-2023, reporting the first error where it finds it ([CAP-044: Verilog and SystemVerilog read by slang](CAP-044.md#reading-verilog)). What the kinds cannot
hold is refused: a macro used where a whole expression isn't, protected text, and forms slang accepts that IEEE 1800
does not.

## Open questions

- **Found by mbse-expressions' stage 6** (CAP-231, [its As built](CAP-231.md#as-built-mbse-expressions)), to assess in
  mbse-programs' port, not fixed there: `AnonymousProgram` is missing from the reader's items, so reading one raises
  `KeyError` rather than `ParseError`; `randomize(null)`, and `randomize` arguments that are not identifiers, are
  refused; a `ParenthesizedPropertyExpr` holding a match list is refused (perhaps never valid); a pattern's parentheses
  are dropped, which [CAP-231: the SystemVerilog expression dialect, complete](CAP-231.md#decided) keeps as a kind (Q5); and mbse-programs does not import against today's mbse-schemas (`Visitors.Native` missing).
