# CAP-022: booleans as checkboxes

*Implements* [FEA-007: property kinds](../features/FEA-007.md). Index entry:
[capabilities/README.md](README.md#CAP-022).

Every `Schemas.OfBool` property is shown and edited as a checkbox, in the
object inspector ([CAP-017: object inspector](CAP-017.md)) and the adjacency inspector ([CAP-018: adjacency inspector](CAP-018.md)).

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 24)** **Booleans as checkboxes**: a `Schemas.OfBool`
  value is a read-only checkbox in view mode, labelled by its property's name, and a checkbox in the editor; an absent
  boolean reads as unchecked, and is written only where the user changes it. The editor's fields (`Fields`) are shared
  by the object inspector and the adjacency inspector, and `editableProperties` gives them for an object schema or a
  relation's entries.
