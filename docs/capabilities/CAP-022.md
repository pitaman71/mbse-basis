# CAP-022: booleans as checkboxes

*Implements* [FEA-007: property kinds](../features/FEA-007.md). Index entry:
[capabilities/README.md](README.md#CAP-022).

Every `Schemas.OfBool` property is shown and edited as a checkbox, in the
object inspector ([CAP-017: object inspector](CAP-017.md)) and the adjacency inspector ([CAP-018: adjacency inspector](CAP-018.md)).
