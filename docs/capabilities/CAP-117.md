# CAP-117: extension adjacencies to any relation

*Implements* [FEA-031: schemas as extensible data](../features/FEA-031.md), [FEA-020: refinable models](../features/FEA-020.md).

## Design

Not built:

### The limit Parametrics met

*Since store overhaul 4m, `Parametrics` is such an extending module, installed before use: it gives `Schemas.OfParameter` its
`for_value` and `for_object` and every kind its `parameters`, which the core no longer declares; the parameters of
section 4 and of Decided, 6 in [FEA-024: expressions as data](../features/FEA-024.md#decided) and 14 in [CAP-112: parameters modeled as schema data](CAP-112.md#decided) are its ([CAP-112: parameters modeled as schema data](CAP-112.md)). The entries a
transaction writes from a schema object the store held before it began are written at once, in the transaction, as
data's are, not when it commits. An adjacency that schema extension adds is still to a relation of two links and no properties
(Decided, 18 in [CAP-116: framework schemas extended, checked](CAP-116.md#decided) and 22 in [FEA-024: expressions as data](../features/FEA-024.md#decided)), which keeps `Parametrics` from installing the adjacencies of its parameter assignments and parameter bindings: open.*

## Decided

As the user decided (2026-11-20), for a kind's membership in a standard edition,
`Expressions.Framework.HasStandard(kind, standard)`, which gains optional bool properties `before` and `after`
([the grammar clauses proposal](../../proposals/GRAMMAR-CLAUSES.md), Decided in stage 3, 1 (b)) and is read through the
extension adjacency `standards`: an adjacency that schema extension adds may be to a relation with properties, a
schema builder's member of it holding entries with their properties and links, as a proxy's adjacency does, rather
than the properties moved elsewhere ("1 (b) - I thought this was already done"; "yes send it over"). This lifts the
limit of 18 in [CAP-116: framework schemas extended, checked](CAP-116.md#decided) as to properties; an adjacency to a
relation of more than two links stays refused, open.
