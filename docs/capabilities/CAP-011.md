# CAP-011: relation browser

*Implements* [FEA-004: index site browser views](../features/FEA-004.md). Index entry:
[capabilities/README.md](README.md#CAP-011).

A large UI view used to browse relation entries.
Each relation entry is represented by a section inside of which 
there is a chip showing the relation entry properties aside
chip views for each linked object.

Entries that link a counted object are left out (short-term tech debt).

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 8)** **CAP-011's entries** come from [CAP-007: detail view](CAP-007.md) with `x` given each app schema
  ([FEA-003: no-code logical views](../features/FEA-003.md#view-kinds): `detail` takes a schema as `label` does), which
  holds every entry of each object's named adjacencies; each entry once, grouped by relation in the store's order, in
  the order met. Each linked object's chip is its [CAP-006: chip view](CAP-006.md) chip from the object browser's views,
  or, where that is not loaded, its label view from the detail frame. An entry's own chip is its relation, its links'
  names and its properties. An entry is not an object, so it is not inspected.
