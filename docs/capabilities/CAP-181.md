# CAP-181: parameters wherever literals may appear

*Implements* [FEA-033: model parameters](../features/FEA-033.md). Index entry: [capabilities/README.md](README.md#CAP-181). *Relates to* [CAP-114: parameter bindings are substituted and checked](CAP-114.md).

## Design

Not built. As the user wrote it: "anywhere a literal may appear, a parameter may alternatively appear". Substituting
a binding where its definition is used, and expression parameters, are [CAP-114: parameter bindings are substituted and checked](CAP-114.md)'s; this
capability is a parameter accepted in every place a literal is.
