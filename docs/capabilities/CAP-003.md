# CAP-003 · schema inspector

From the workspace's `VISUALIZATION.md`. *Implements* [FEA-003](../features/FEA-003.md). Index entry:
[capabilities/README.md](README.md#CAP-003).

Given a schema's name, UI can obtain the full
detail for that schema. Definitions for unnamed schemas
must be included in the response. Named schemas
may be included only in referenced form.
