# CAP-002 · named schema list

From the workspace's `VISUALIZATION.md`. *Implements* [FEA-003](../features/FEA-003.md). Index entry:
[capabilities/README.md](README.md#CAP-002).

Backend has a designated endpoint which returns a list
of every named schema.

While CAP-003 is blocked (mbse-schemas cannot yet write one schema object
as a document), it returns the store's whole schema snapshot instead, from
which the client's store takes every schema.
