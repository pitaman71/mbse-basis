# CAP-169: mutations written in their smallest form

*Implements* [FEA-032: schema loading and wire alignment](../features/FEA-032.md). Index entry: [capabilities/README.md](README.md#CAP-169).

## Design

Not built: checked in the code, `Plain.ToPlain` takes no mode but `flat`, and writes one form of each change. As the serialization design has it:

A change can be written in more than one form (`OfProperty.Set`, or `OfProperty.AsAny` then `OfAny.Set`, ...). Which form
ToPlain writes is a serializer mode: by default, the form whose serialized mutation is smallest, a tie going to the
shallowest form; the mode is configurable. A reader accepts every form.
