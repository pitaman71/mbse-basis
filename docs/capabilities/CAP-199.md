# CAP-199: journals as queryable stores (mbse-journals)

*Implements* [FEA-006: persistence](../features/FEA-006.md). Index entry: [capabilities/README.md](README.md#CAP-199). *Relates to* [CAP-129: journals replayed by execution](CAP-129.md), [CAP-077: changes explained across runs](CAP-077.md).

## Design

Not built. A transaction's expression as data, and journals replayed by executing it, are built in mbse-schemas
([CAP-129: journals replayed by execution](CAP-129.md)); diffing stores is what [CAP-077: changes explained across runs](CAP-077.md) waits on. As the user wrote it:

> Create a new repo `mbse-journals`.
>
> Journal is an extension of Store and may be queried.
> Any Journal may optionally predicates that describe portion contained.
>
> Schema-kind-specific serializable mutation protocols are defined in
> `mbse/Journals/Framework/Mutations` { <OfSchemaKind> ... | OfStore }
>
> All Builders - whether proxy or generated - must implement the appropriate mutation protocol. Can this be accomplished without littering the syntax with lots of extra '.get' and '.set' calls?
>
> Serializable mutation dataclasses are implemented in
> `mbse/Journals/Proxies/Mutations` { <OfSchemaKind> ... | OfStore }
> As usual they should use the builder/visitors/metaschema pattern for serialization.
>
> - mbse/Journals/Framework/Journals `class OfStore(Protocol) # protocols of streaming atomic transactions
> - mbse/Journals/Framework/Journals `class OfSender(Protocol) # transmitter endpoint
> - mbse/Journals/Framework/Journals `class OfReceiver(Protocol) # receiver endpoint
> - mbse/Journals/Cache/Journals OfStore # in memory persistent store
> - mbse/Journals/File/Journals OfStore # local filesystem copy
>
> - `Journal.from_batch(self, Mutations.Transaction)`
> - `Journal.to_batch(self) -> Mutations.Transaction`
> - `Journal.diff(a: Stores.OfStore,b: Stores.OfStore)`
> - `Sender.send(source: Stores.OfStore)`
> - `Sender.subscribe(obs: Observable[Mutations.Transaction])`
> - `Receiver.observe() -> Observer[Mutations.Transaction]`
