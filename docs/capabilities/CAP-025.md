# CAP-025: schemas open in content

*Implements* [FEA-020: refinable models](../features/FEA-020.md). Index entry: [capabilities/README.md](README.md#CAP-025).

## As built: mbse-schemas

Met in mbse-schemas 0.10.0, as the index records.

### Open in content

- **Open in content.** Nothing is mandatory except as specified by a constraint, no cardinality is assumed, and
  checking is three-valued: a constraint over a value that is absent, or a parameter that is unbound, is unknown, not
  false.
