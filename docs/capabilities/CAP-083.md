# CAP-083: policies with guards and distributions

*Implements* [FEA-021: every generation ambiguity a parameter](../features/FEA-021.md), [FEA-017: AI in the loop via the model trace](../features/README.md#FEA-017), [FEA-018: humans in the loop via the model trace](../features/README.md#FEA-018).

## Design

### Policies, in the core

- **Policies, in the core**, are clauses that each weigh one transform's candidates with given arguments. Guards (a
  predicate over the match) and distributions over a parameter's domain are designed above and not built yet.

### Policies as data

- `Transforms.Policy`: clauses, each a transform, a guard (a predicate's name and arguments), preferences over
  arguments or a distribution over a parameter's domain, and a weight.

## Open questions

- **A dependency on mbse-patterns.** Distributions are mbse-patterns', so policies weighed by them would make
  mbse-transforms depend on mbse-patterns ([mbse-transforms' charter](https://github.com/pitaman71/mbse-transforms/blob/main/docs/proposals/charter/README.md#risks), Risks).
