# CAP-305: simplification's options, chosen up front

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). *Applies* [PRI-014: every ambiguity a decision](../PRINCIPLES.md#PRI-014), [PRI-042: optionality kept](../PRINCIPLES.md#PRI-042), [PRI-046: simplification, not evaluation](../PRINCIPLES.md#PRI-046). *Relates to* [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md), [CAP-297: simplification in every binding state](CAP-297.md).

## Decided

The user's decision (2026-11-15), of the choices mbse-expressions' simplification step 2 settled where two behaviors
are defensible ([the port's API, Settled in simplification](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/port/API.md#settled-in-simplification-for-the-users-review)):
"these sounds like options to be added not decisions to be made". Each such choice is a parameter of simplification
that its caller chooses up front, the behavior built in 0.11.0 its default; confirmed as these six, the user
answering "Yes, as listed". Two choices of that step are not options: a SystemVerilog cast's operand sized as an
assignment (API 365), which is IEEE 1800's rule, and a guarded subterm staying in the residual (API 374), which fixed a
bug.

## Design

Each option a parameter of the scope a simplification runs in, beside a time literal's unit and `min:typ:max`'s
choice, which SystemVerilog's scope already takes (API 367); named and shaped when built.

| Option | Default (0.11.0) | Alternative | API |
|---|---|---|---|
| A C or C++ value whose type has no literal (`char`, `short`) | stays in the residual | written as a cast of a literal, `(short)3` | 352 |
| A format spec Python would refuse | stays in the residual | raises Python's `ValueError` | 345 |
| `is` between equal immutable values, which Python leaves to its implementation | stays in the residual | CPython's answer | 344 |
| A result the platform's math library decides (a complex power that is no integer one; SystemVerilog's `$ln`, `$sin`, ...) | complex powers stay; SystemVerilog's math functions fold by the host's library | always stay, or always fold by the host's library | 347, 371 |
| A SystemVerilog time literal with no time unit; `min:typ:max` | stays; `typ` | a default unit; `min` or `max` | 367 |
| An error in a subterm its language always evaluates | raises, as the expression would in its language | stays in the residual, named | 328 |
