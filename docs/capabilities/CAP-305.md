# CAP-305: simplification's options, chosen up front

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). *Applies* [PRI-014: every ambiguity a decision](../PRINCIPLES.md#PRI-014), [PRI-042: optionality kept](../PRINCIPLES.md#PRI-042), [PRI-046: simplification, not evaluation](../PRINCIPLES.md#PRI-046). *Relates to* [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md), [CAP-297: simplification in every binding state](CAP-297.md).

## Decided

On 2026-11-15 the user reviewed the choices that mbse-expressions' simplification step 2 had settled where two
behaviors are defensible
([the port's API, Settled in simplification](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/port/API.md#settled-in-simplification-for-the-users-review)).
The user decided: "these sounds like options to be added not decisions to be made". Each such choice therefore becomes
a parameter of simplification, which the caller chooses before simplifying. The behavior that version 0.11.0 built
becomes each parameter's default. The user confirmed the six options below, answering "Yes, as listed".

Two choices of the same step are not options. The first is that a SystemVerilog cast sizes its operand as an
assignment does (API 365), because IEEE 1800 states that rule. The second is that a guarded subterm stays in the
residual (API 374), because that choice fixed a bug.

## Design

Each option is to be a parameter of the scope in which a simplification runs. SystemVerilog's scope already takes two
such parameters, a time literal's unit and the choice for `min:typ:max` (API 367). Each option's name and shape will
be decided when the option is built. In the table, each row is one option: the default column describes what the
simplifier does now, and the alternative column describes what the caller may choose instead.

| Option | Default (0.11.0) | Alternative | API |
|---|---|---|---|
| A C or C++ value whose type has no literal (`char`, `short`) | stays in the residual | written as a cast of a literal, `(short)3` | 352 |
| A format spec Python would refuse | stays in the residual | raises Python's `ValueError` | 345 |
| `is` between equal immutable values, which Python leaves to its implementation | stays in the residual | CPython's answer | 344 |
| A result the platform's math library decides (a complex power that is no integer one; SystemVerilog's `$ln`, `$sin`, ...) | complex powers stay; SystemVerilog's math functions fold by the host's library | always stay, or always fold by the host's library | 347, 371 |
| A SystemVerilog time literal with no time unit; `min:typ:max` | stays; `typ` | a default unit; `min` or `max` | 367 |
| An error in a subterm its language always evaluates | raises, as the expression would in its language | stays in the residual, named | 328 |
