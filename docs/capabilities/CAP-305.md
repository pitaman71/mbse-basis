# CAP-305: simplification's options, chosen up front

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). *Applies* [PRI-014: every ambiguity a decision](../PRINCIPLES.md#PRI-014), [PRI-042: optionality kept](../PRINCIPLES.md#PRI-042), [PRI-046: simplification, not evaluation](../PRINCIPLES.md#PRI-046). *Relates to* [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md), [CAP-297: simplification in every binding state](CAP-297.md).

## Decided

Where simplification could follow either of two defensible behaviors, the behavior is a parameter of simplification,
which the caller chooses before simplifying. The user decided it so: "these sounds like options to be added not
decisions to be made". The user confirmed the options in the table below, and the table gives each option's
default. The first option's default is the cast, because leaving the value in the residual would not meet the
criterion of [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md#decided), a closed
constructor expression at the root.

Two behaviors are not options. The first is that a SystemVerilog cast sizes its operand as an
assignment does (API 365), because IEEE 1800 states that rule. The second is that a guarded subterm stays in the
residual (API 374), because that choice fixed a bug.

## As built: mbse-expressions

mbse-expressions 0.11.0 holds this capability's build. A scope takes its options as a mapping,
`Symbolics.Variables(variables, options)`, and a scope that `bind` makes keeps them. `scope.option(name, default)`
reads an option, and `Symbolics.option(scope, name, default)` reads one from any scope. Each dialect's simplifier reads
its own options, and it raises `ValueError` before it simplifies anything when an option holds a value that the option
does not take. A caller who chooses nothing gets each option's default. The table names each option, the scope that
takes it, and the items of [the port's API](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/port/API.md#settled-in-cap-305s-options-for-the-users-review) that hold the
detail.

| Option | Scope | What it chooses | Default | Alternative | API |
|---|---|---|---|---|---|
| `errors` | every scope | an error in a subterm that the language always evaluates | `"raise"`: the error raises, as the expression would raise in its language | `"stay"`: the subterm stays in the residual, named, class (b) | 401, 402 |
| `casts` | C's and C++'s | a value whose type has no literal of its own (`char`, `short`) | `"write"`: the value is written as a cast of a literal, `(short)3` | `"stay"`: the value stays in the residual | 408, 409 |
| `specs` | Python3's | a format spec that Python would refuse | `"stay"` | `"raise"`: Python's `ValueError`, with CPython's message | 403, 404 |
| `locale` | Python3's | a format spec of type `n`, whose result depends on a locale | `"stay"` | a locale given as data, as `localeconv()` describes one | 404 |
| `text` | Python3's | a field whose text is the implementation's (an object's address, a set's iteration order) | `"stay"` | `"cpython"`: the text is written as CPython writes it | 407 |
| `identity` | Python3's | `is` between equal immutable values, which Python leaves to its implementation | `"stay"` | `"cpython"`: CPython's answer, for the values that CPython keeps one object of | 405 |
| `math` | Python3's | a complex power whose exponent is not an integer | `"stay"` | `"host"`: the power folds by the host's math library | 406 |
| `math` | SystemVerilog's | `$ln`, `$sin` and the other math functions that are not exact | `"host"`: they fold by the host's math library | `"stay"`: they stay in the residual, named | 410, 411 |
| `timeunit`, `timeprecision`, `mintypmax` | SystemVerilog's | a time literal's unit and precision, and the choice of `min:typ:max` | no unit, so a time literal stays; `typ` | a unit and a precision; `min` or `max` | 410 |
| `byteorder` | SystemVerilog's | the byte order of `%u` and `%z` in a folded `$sformatf`, which IEEE 1800 leaves to the host | `"little"`, as both stored ABIs are | `"big"` | 412 |

## Decided by an agent, for review

Each decision remains proposed until the user reviews it; the API items above hold the detail.

- **(mbse-expressions 66, the framework, API 402)** The residue that `errors`' value `"stay"` leaves has class (b),
  because an expression that raises has no value of its own.
- **(mbse-expressions 63, C and C++, API 409)** The framework's `construct` hook receives no scope, so the C family's
  simplifier reads `casts` through a subclass of the framework's `Simplifier`, which hands the expression to a second
  simplifier that writes no cast. Passing the scope to `construct` would let every dialect read an option there.
- **(mbse-expressions 65, Python3, API 403 to 407)** Under `text`'s value `"cpython"`, the TypeScript implementation
  leaves in the residual each text that depends on a CPython object, such as an address or a set's order; the
  difference is listed in mbse-expressions' EQUIVALENCE. Under `identity`'s value `"cpython"`, CPython's answer is
  given only for the values that CPython keeps one object of: the ints from -5 to 256, `()`, `''` and `b''`.
- **(mbse-expressions 64, SystemVerilog, API 410 to 412)** The SystemVerilog dialect's scope takes `timeunit`,
  `timeprecision` and `mintypmax` as options, so that one mechanism holds every parameter of simplification. Under
  `math`'s value `"stay"`, a real `**` stays as well as `$pow`, and `$sqrt`, `$floor` and `$ceil` still fold, because
  IEEE 754 makes them exact.
