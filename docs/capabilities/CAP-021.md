# CAP-021: lists ordered by creation

*Implements* [FEA-005: inspector views](../features/FEA-005.md), [FEA-046: a React, TypeScript and CSS-in-TS UI stack](../features/FEA-046.md).

Adjacency lists order their linked objects by creation time where
provenance ([CAP-015: transaction provenance](CAP-015.md)) is present, and in frame order otherwise.

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 32)** **Creation order**: an adjacency list is sorted
  by creation time where every item it shows has one, and kept in frame order otherwise; ties keep frame order.
