# CAP-299: simplification across a sub-dialect

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). *Applies* [PRI-046: simplification, not evaluation](../PRINCIPLES.md#PRI-046). *Relates to* [CAP-098: dialects over one framework](CAP-098.md), [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md).

## Design

This capability covers the class (a) kinds of two sublanguage dialects, as well as expressions in which a host
dialect reads a sublanguage's terms.

- **C Preprocessor's `definedexpression`.** The expression `defined(X)` is 1 when the macro `X` is defined and 0
  otherwise (ISO/IEC 9899, 6.10.1). The scope names the defined macros.
- **SystemVerilog Constraints' seven kinds**: `constraintblock`, `expressionconstraint`, `implicationconstraint`,
  `conditionalconstraint`, `foreachconstraint`, `uniqueconstraint` and `distexpression`. IEEE 1800's clause 18 gives
  each kind a truth value over the values of its variables, so checking given values against a constraint is a
  simplification with no statements.

## Decided

- The user decided that these kinds belong to this capability, not to
  [CAP-295: simplification of single-dialect expressions with literal leaves](CAP-295.md).
