# CAP-007: detail view

*Implements* [FEA-003: no-code logical views](../features/FEA-003.md). Index entry:
[capabilities/README.md](README.md#CAP-007).

This is a full-sized logical view of an object.

Given a `References.OfObject`, 
UI can obtain a logical view template, the response for which
comprises properties and adjacencies of an object for display in a detail inspector over the full set of schema-defined properties and 
adjacencies.

## As built

mbse-rest serves this as the `detail` view kind: what its frames carry is in [FEA-003: no-code logical views](../features/FEA-003.md#view-kinds)'s view kinds, beside the other three.

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-rest 8)** **Detail** includes every named adjacency (anonymous ones are not members), entries in the schema's
  adjacency order and each adjacency's own, and the `label` view of each linked object, so that the inspector can show
  each entry without a second request ([FEA-003: no-code logical views](../features/FEA-003.md), "sensibly nested").
