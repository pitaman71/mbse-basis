# CAP-082: completeness reported

*Implements* [FEA-059: transforms of models, applied step by step and certified](../features/README.md#FEA-059), [FEA-017: AI in the loop via the model trace](../features/README.md#FEA-017), [FEA-018: humans in the loop via the model trace](../features/README.md#FEA-018).

## Design

### Completeness

- **A session is done** when no candidate is left and no composite is open. Checking that every element some transform
  could match has been rewritten (**completeness**: "nothing rewrites union `Reach`", where today's transpilers say "a
  spread in an object literal is not supported") is designed, not built.
