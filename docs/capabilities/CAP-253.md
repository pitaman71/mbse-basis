# CAP-253: counted objects (serialization)

Counted objects do not survive transit between backend and frontend. A counted object has no reference
([CAP-130: references to objects, entries and frames](CAP-130.md)), so what is serialized by reference leaves it out:
the no-code views neither record nor transmit one (a frame that binds one is left out of the stream, and an entry
that links one out of `entries`), and the object and relation browsers leave out such objects and entries. This
capability was to serialize counted objects where they are left out.

Superseded by [INI-082: eliminate counted objects](../../proposals/PRIORITIES.md#ini-082--eliminate-counted-objects): counted objects are deprecated, so none is left to serialize.
