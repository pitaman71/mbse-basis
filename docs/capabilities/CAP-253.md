# CAP-253: counted objects (serialization)

*Implements* [FEA-026: deterministic object identity](../features/FEA-026.md). *Relates to* [CAP-133: no durable references to counted objects](CAP-133.md), [FEA-003: no-code logical views](../features/FEA-003.md), [CAP-010: object browser](CAP-010.md), [CAP-011: relation browser](CAP-011.md).

## Design

Not built. A counted object has no reference ([CAP-130: references to objects, entries and frames](CAP-130.md)), so
what is serialized by reference leaves it out: the no-code views neither record nor transmit one (a frame that binds
one is left out of the stream, and an entry that links one out of `entries`), and the object and relation browsers
leave out such objects and entries. This capability is that tech debt: counted objects serialized where today they are
left out.

  the visualization capabilities.
