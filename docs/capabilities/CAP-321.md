# CAP-321: changes gathered as schema data

*Implements* [FEA-030: clean mutation-based transactional API](../features/FEA-030.md) and [PRI-018: no model needs code to read or write](../PRINCIPLES.md#PRI-018). *Relates to*
[CAP-270: a transaction's changes observed at its commit](README.md#CAP-270), [CAP-318: support for decoupled code](README.md#CAP-318),
[the Context + References + Changes cleanup proposal](../../proposals/CONTEXT-REFERENCES-CHANGES.md).

mbse-schemas' `Changes` gathers what a transaction changed as a `Changes.Transaction` value, through its builders, with
no bespoke structure between, and its schemas are value objects that name what they change by `References`. Applying a
journal, and a cache layer's rewriting of a layer below's changes, read a `Changes.Transaction` through the visitors.

## Decided

As the user decided, passed on by the session that holds the decoupled code proposal, in the user's words:

- **Removal as well as insertion**: "`Changes` needs `Remove` as well as `Insert`."
- **References**: "`Changes` should probably use `References` if it doesn't already". An entry's holder and links,
  `Mutations.OfLink.Set` today, name their objects as `References` do.
- **A kind is a union of its actions**: "I kind of prefer: `Changes.OfKind` as a union of `Changes.OfKind.Action`."
  `Changes.OfEntry` is a union of `Changes.OfEntry.Insert` and `Changes.OfEntry.Remove`, in place of a `verb` written
  as a string, and `Changes.OfProperty` a union of `Changes.OfProperty.Set` and `Changes.OfProperty.Clear`.
  `Changes.Change` stays the union of the kinds. The user agreed to this reading ("yes").
- **Value objects**: "Also `Changes.*` should be entirely value objects". Every `Changes` schema is one already, and
  stays one.

## Open questions

- **A change within a container value.** `Changes.OfProperty` carries the verbs that `Mutations.OfProperty` writes,
  among them verbs nested within a container value, such as inserting an element. Does each such verb become an
  action of its own, as `Changes.OfProperty.Insert`, or is a change to a container value written as a `set` of the
  whole value?
