# CAP-071: an unrestricted `OfAny` on the wire

*Implements* [FEA-006: persistence](../features/README.md#FEA-006), [FEA-032: schema loading and wire alignment](../features/FEA-032.md). Index entry: [capabilities/README.md](README.md#CAP-071). *Relates to* [FEA-020: refinable models](../features/FEA-020.md).

## As built: mbse-schemas

Not designed, and left as it was when [CAP-069: wire format shorthand (scalars)](CAP-069.md#decided) was built (its point 5): an unrestricted `OfAny`'s value is tagged by one level, `{"int": 1}`, `{"crm.Phone": {...}}`.

An unrestricted `OfAny` always tags, since every schema is possible, and takes a value given as itself, never a Spec ([CAP-157: values of any schema, restricted or not](CAP-157.md#decided), "`OfAny` returns").
