# CAP-173: spec items written through ordinary builders over a mutation sink

*Implements* [FEA-037: the framework built on its own protocols](../features/FEA-037.md). Index entry: [capabilities/README.md](README.md#CAP-173). *Relates to* [CAP-136: one finisher for every build](CAP-136.md).

## Design

Not built: a spec item (`lambda _: _.x.capabilities([_.y])`) is written through `Transactions._Recorder`
(TypeScript's `Recorder`), a tracer shaped like `Visitors.OfObject` that implements only `as_schema()` and named
members, with no `as_properties` or `as_adjacencies`, and parallel classes (`_RecordedProperty`,
`_RecordedAdjacency`, `_RecordedSpec`) that duplicate the visitors' behavior.

To build: the ordinary builders data objects get write a spec item, backed by a sink that records mutations instead of
writing a store, as builders within a transaction write to a `Proposals` overlay; each symbol's schema is taken from
the builder's context. It is coordinated with [CAP-136: one finisher for every build](CAP-136.md): the sink is the `Writer` a spec callback would
be given ([CAP-143: specs declarative, no read-modify-write](CAP-143.md#design)).
