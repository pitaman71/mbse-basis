# CAP-009: schema browser

*Implements* [FEA-004: index site browser views](../features/FEA-004.md). Index entry:
[capabilities/README.md](README.md#CAP-009).

A large UI view used to browse defined schemas. 
Each schema is represented by a section. Inside of each section
is the label and description for the schema itself. Then
there is a scrollable list of object preview chips, in frame order for now.

Only schemas which have a *registered name* and a description are included,
and of those only the app's reference object schemas: framework schemas
(`Schemas.*`, `Paths.*`, `Mutations.*`, `References.*`) are excluded.

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 6)** **CAP-009's schemas**: every registered name outside the framework's modules (`Schemas`, `Paths`,
  `Mutations`, `References`) whose schema is marked `ref` (a reference object schema, singletons' included) and has a
  non-empty description. A schema's label is its registered name. Its chips are [CAP-006: chip view](CAP-006.md) with
  `x` given the schema, in a row scrolled sideways.
