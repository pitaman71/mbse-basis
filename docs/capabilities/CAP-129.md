# CAP-129: journals replayed by execution

*Implements* [FEA-030: transactions](../features/FEA-030.md). Index entry: [capabilities/README.md](README.md#CAP-129).

## As built: mbse-schemas

Met in mbse-schemas 0.22.0: a journal is a list of transactions as submitted, replayed by executing each, "built as designed" (the [store overhaul](../../../mbse-schemas/docs/proposals/store-overhaul/README.md), 4f), released as 0.22.0.

## Decided

As the user decided: adopted, each the rule as stated, quoted where the wording matters.

- **(object identity 56)** Sharding is not recorded: `Mutations.OfShard` (52 in [CAP-144: transactions sharded and run in parallel](CAP-144.md#decided)) is the executor's, not part of the transaction on the wire, and a
  journal holds transactions as submitted, replayed by executing them again.
