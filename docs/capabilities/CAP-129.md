# CAP-129: journals replayed by execution

*Implements* [FEA-030: transactions](../features/FEA-030.md). Index entry: [capabilities/README.md](README.md#CAP-129).

## As built: mbse-schemas

Met in mbse-schemas 0.22.0: a journal is a list of transactions as submitted, replayed by executing each, "built as designed" (the [store overhaul](../../../mbse-schemas/docs/proposals/store-overhaul/README.md), 4f), released as 0.22.0.

### Transactions on the wire

A transaction is written as its expression (object identity 56, Decided, below; Store overhaul, 4f), nested, since
reading it executes it: `Plain.ToPlain(store).Transaction(tx)` writes it, `Plain.FromPlain(store).Transaction(plain)`
builds it again through the store's builders, and `store.transaction(...)` executes it. A journal is a list of them, as
submitted, replayed by executing each in order; a transaction's imperative scope has no expression, so none (103).

```json
{"uid": "6f1c4e2a", "mutations": [{"upsert": {"key": "k", "exists": [{
  "symbols": {"book": {"schema": [{"$ref": <crm.Book's path>}]}, "ada": {"schema": [{"$ref": <crm.Person's path>}]}},
  "spec": [{"ada": [{"as_property": {"name": "name", "mutations": [{"set": {"value": "Ada"}}]}}]}]}]}}]}
```

- An object is a mapping of its properties, then its named adjacencies, in its schema's order.
- An adjacency's entries: where its relation has one other link and no properties, what each links (the peer
  shorthand); where it has one other link and one property, a mapping of that property to what each links (a
  pattern's symbols, by name); else each entry's links and properties.
- What an entry links is nested where it has no path, a term linked from one place or a schema object with no name of
  its own, and tagged with its kind where the link is a kind union (`{"upsert": ...}`), or with its schema's name where
  several schemas fill the link (`{"Schemas.OfUnion": ...}`); anything else is `{"$ref": path}`.
  Paths are deprecated in favor of References ([CAP-130: references to objects, entries and frames](CAP-130.md#decided), References): a request or a response that
  designates an object, a relation entry or a frame carries a `References.OfObject`, `OfEntry` or `OfFrame` value,
  written as any value is. The wire keeps writing `$ref` as a path until Paths are removed.

What a store with `Provenance` installed records of a transaction on the wire is [CAP-134: transactions recorded with provenance](CAP-134.md); a pattern's spec is written as recorded ([CAP-137: patterns of symbols, variables and specs](CAP-137.md)).

## Decided

As the user decided: adopted, each the rule as stated, quoted where the wording matters.

- **(object identity 56)** Sharding is not recorded: `Mutations.OfShard` (52 in [CAP-144: transactions sharded and run in parallel](CAP-144.md#decided)) is the executor's, not part of the transaction on the wire, and a
  journal holds transactions as submitted, replayed by executing them again.
