# CAP-295: simplification of single-dialect expressions with literal leaves

*Implements* [FEA-024: expressions as data](../features/FEA-024.md). *Applies* [PRI-046: simplification, not evaluation](../PRINCIPLES.md#PRI-046). *Relates to* [CAP-099: partial evaluation](CAP-099.md), [CAP-106: expressions evaluated three-valued](CAP-106.md).

## As built: mbse-expressions

Built in mbse-expressions 0.11.0 (unreleased), simplification's step 2, one family at a time over the framework of
step 1 (#48): TypeScript5 (#49, #50), then Python3 (#51), C and C++ (#52) and SystemVerilog (#53), integrated in #54.
Each family folds, by its own language's semantics, every kind and every shape within a folded kind that
[the evaluation inventory](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/dialects/README.md#evaluation-what-is-refused-and-why)
gives class (a), statement-free with a value its language defines; Patterns, MATLAB and Excel folded theirs already.
A value with a literal of its dialect folds to it; one with none (a closure, a set, an array, a C `char`) stays, its
subterms simplified. What stays is named, with its class. The detail is each family's As built in
[the evaluation proposal](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/evaluation/README.md#as-built-the-framework-0110),
which this section only bridges:

- **TypeScript5**, by ECMA-262's abstract operations, modeled alike in both languages
  ([As built: TypeScript5](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/evaluation/README.md#as-built-typescript5-0110)).
  ECMAScript's built-in methods and host values stay, waiting on
  [CAP-301: simplification delegated to a surrogate dialect](README.md#CAP-301).
- **Python3**, by CPython 3.14's semantics, which TypeScript models
  ([As built: Python3](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/evaluation/README.md#as-built-python3-0110)):
  constants and complex numbers, displays, f-strings and t-strings, slices, comprehensions, lambdas and keywords.
- **C and C++**, by ISO/IEC 9899 and 14882 in the types and layouts their holder's ABI stores
  ([As built: C and C++](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/evaluation/README.md#as-built-c-and-c-0110);
  [CAP-267: C and C++ terms read under the ABI their holder names](CAP-267.md)).
- **SystemVerilog**, by IEEE 1800-2023, a subterm folding wherever 11.6's sizing of the whole expression keeps its
  meaning ([As built: SystemVerilog](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/evaluation/README.md#as-built-systemverilog-0110)).

What stays of class (a), as the inventory's counts give it: C Preprocessor's `defined` and SystemVerilog
Constraints' 7 kinds, and 13 shapes within folded kinds, each one the two implementations cannot yet compute alike (a
complex power that is no integer one, a locale's format, a layout no ABI dialect stores).

## Decided by an agent, for review

Recorded in [the port's API, Settled in simplification](https://github.com/pitaman71/mbse-expressions/blob/main/docs/proposals/port/API.md#settled-in-simplification-for-the-users-review),
items 334 to 373, which hold the detail; each *proposed* until reviewed. Where one settles a fork between two
defensible behaviors, the user decided (2026-11-15) that it becomes an option, the choice here its default:
[CAP-305: simplification's options, chosen up front](CAP-305.md).

- **(mbse-expressions 49, TypeScript5, API 334 to 340)** ECMAScript's values and abstract operations as a module of
  their own, `Abstract`, named as ECMA-262 names them; nothing reachable beyond the scope, a built-in method read by
  its name and left in the residual; values written back as ECMAScript writes them; BigInt's size at V8's limit.
- **(mbse-expressions 51, Python3, API 341 to 350)** A lambda a closure with CPython's binding and messages; `is`
  between equal immutable values left as (b), Python leaving it to the implementation; a format spec Python refuses
  left in the residual rather than raising `ValueError`; complex arithmetic as CPython's, `abs` the correctly rounded
  `hypot`; a complex power that is no integer one left in the residual.
- **(mbse-expressions 52, C and C++, API 351 to 362)** A value of a type with no literal (`char`, `short`) left in the
  residual, not written as a cast, its arithmetic folding; a floating value written as a literal where a binary64
  literal spells it exactly (`3.0L`); the conditional converting its chosen operand to the two operands' common type
  where the other's type is known unevaluated; types matched by C's identity of types; C++'s packs a scope's.
- **(mbse-expressions 53, SystemVerilog, API 363 to 373)** A cast to an integral type sizing its operand as an
  assignment does (6.24.1), which changes the earlier behavior (`16'(8'hFF+8'h01)` is `16'h0100`); a time literal by
  the scope's time unit, with no default; named and default arguments through the scope's `Subroutine`; a constant
  pattern matched by `===`.
