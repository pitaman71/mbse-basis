# CAP-168: containers by an index neither ordered nor hashable read back

*Implements* [FEA-025: serialization behavior conventions in schema](../features/FEA-025.md). Index entry: [capabilities/README.md](README.md#CAP-168).

## Design

Not built. Of the containers built in V5 ([CAP-108: relations as scalable containers](CAP-108.md)), what was left: "not yet: reading a container whose index is neither ordered nor hashable from a snapshot (its index would have to be built as a standalone value object)". Reading one refuses it: "a container whose index is neither ordered nor hashable is not read from snapshots yet".
