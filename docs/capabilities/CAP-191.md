# CAP-191: private tenancy, behind login with sessions

*Implements* [FEA-040: tenancy](../features/FEA-040.md). *Relates to* [CAP-177: sessions and identities from a validated token](CAP-177.md).

## Design

Not built. As the user wrote it, "private (intermediate)":

> - system requires login for any access
> - security configurations via patterns shared and enforced across services 
>   and UI
> - sessions uid is allocated on login and renewed with login tokens
> - user/agent identity is recorded in session log
> - session identity is recorded with every transaction
> - transaction request/response signatures recorded in session log

A service writing the session and identity a validated token gives is [CAP-177: sessions and identities from a validated token](CAP-177.md).
