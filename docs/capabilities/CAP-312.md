# CAP-312: a parameter reference in place of anything with a schema

*Implements* [FEA-033: model parameters](../features/FEA-033.md). *Relates to* [CAP-311: references stabilized](README.md#CAP-311),
[CAP-313: parameter references bound and validated](README.md#CAP-313), [CAP-316: one written form for references](CAP-316.md), [the parametrics proposal](../../proposals/PARAMETRICS.md).

Wherever mbse-schemas expects something of a schema, a parameter reference, `References.OfParameter`, may stand in its
place: a property's value, a container's element, a union's branch, or an object that a link links. The proxies,
validation and the plain form apply that one rule, in both languages.

## Decided

As the user decided:

- **A parameter reference stands in for anything with a schema**: "a parameter reference, as a value object, may
  appear in any data structure in place of anything that has a schema." No kind of place is excluded.
- **The expected schema comes from the context**: "As always, the expected schema comes from the surrounding
  context."
- **The wrong kind of thing is a validation error**: "If a parameter reference is bound to the wrong kind of 'thing'
  (e.g. value for reference or vice versa) that is a validation error." Validation reports a parameter assigned a value
  where the context expects an object, bound to an object where it expects a value, or given something of another schema
  ([CAP-313: parameter references bound and validated](README.md#CAP-313)).
- **A parameter reference is read as a kind of `OfAny`**: "parameter ref is just a kind of OfAny :
  Visitors.OfAny.as_parameter()". The visitors of the other kinds read a place that holds a parameter reference as
  empty, as `OfAny` reads a value of another kind, so that a reader which never meets one sees no change.
- **Comparison halts on it**: "Like simplification, comparison halts on a parameter reference and returns unknown,
  undefined, or None as appropriate." Where a comparison meets a parameter reference, it gives its unknown result,
  never equal or unequal.
- **Links are part of it** (the first of the options offered, to finish links before the capability is called met):
  a parameter reference stands in for an object that a link links, as for a value.
- **A relation that owns what it links is the one place excluded** ("yes refusing owneship links is a fine carve
  out"). Every path runs through ownership, so that a relation which owns what it links refuses a parameter reference
  in any of its links, and paths and cascades never meet one.
- **Links between schema objects are deferred** ("yes links b/w schema objects with a type parameter may be
  deferred"). A type parameter standing where a schema object links another, as a property's `schema`, is left to
  [CAP-298: simplification over type parameters](README.md#CAP-298); CAP-312 covers the store's data.
- **It is written marked** ("yes that works"): in the plain form, a parameter reference in place of something of
  another schema is `{"$schema": "References.OfParameter", "name": "n"}`, as
  [CAP-316: one written form for references](CAP-316.md) marks a reference where the reader could take it for a value of the expected schema.
