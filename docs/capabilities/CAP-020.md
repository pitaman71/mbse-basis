# CAP-020: provenance display

From the workspace's `VISUALIZATION.md`. *Implements* [FEA-005: inspector views](../features/FEA-005.md). Index entry:
[capabilities/README.md](README.md#CAP-020).

Where a detail frame carries provenance ([CAP-015: transaction provenance](CAP-015.md)), the inspector shows who
created the object (its creating session's identity), when it was created
and when last modified, in the browser's locale and time zone; an
adjacency list shows each linked object's author and creation time.
