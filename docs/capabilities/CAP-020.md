# CAP-020: provenance display

*Implements* [FEA-005: inspector views](../features/FEA-005.md). Index entry:
[capabilities/README.md](README.md#CAP-020).

Where a detail frame carries provenance ([CAP-015: transaction provenance](CAP-015.md)), the inspector shows who
created the object (its creating session's identity), when it was created
and when last modified, in the browser's locale and time zone; an
adjacency list shows each linked object's author and creation time.

## Decided by an agent, for review

Where this capability was silent, the simplest default consistent with it and with mbse-schemas, each *proposed*
until reviewed, labeled with the repository and number it was decided under.

- **(mbse-react 31)** **Provenance is read, not listed**: a frame's
  framework entries (`Provenance.*`) are kept out of the detail's, the relation browser's and the adjacency lists'
  entries; `Views.provenance` reads them. The inspector shows "created by … · when" and "edited by … · when" under the
  label; each linked object in an adjacency list, "{identity} @ {when}" as its pill's header (mbse-react 33). Times are
  in the browser's locale and time zone (`Intl.DateTimeFormat`). The schema browser leaves out `Parametrics` and
  `Provenance` with the other framework modules.
