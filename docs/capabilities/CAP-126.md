# CAP-126: schema objects read through the store protocol

*Implements* [FEA-028: one API surface for all data access](../features/FEA-028.md). Index entry: [capabilities/README.md](README.md#CAP-126).

## Design

Not built: schema objects are read field by field, outside the protocol, kept as tech debt and taken out of step 4 (4k) with the commit-time rule kept (the [store overhaul](../../../mbse-schemas/docs/proposals/store-overhaul/README.md), Decided, 32).

## Decided

As the user decided: adopted, each the rule as stated, quoted where the wording matters.

- **(object identity 100, its tech-debt clause)** Schema objects are read outside the protocol, field by
  field, for the time being: "that is acceptable for the time being. Retain as tech debt"; their updates within a
  transaction are a `Proposals`' still (96 in [CAP-124: writes all-or-nothing in transactions](CAP-124.md#decided)).
