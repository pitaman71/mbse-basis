# CAP-229: the C expression dialect

*Implements* [FEA-024: expressions as data](../features/FEA-024.md), [FEA-008: expressive program models](../features/FEA-008.md). Index entry: [capabilities/README.md](README.md#CAP-229). *Relates to* [CAP-226: complete expression dialects](CAP-226.md), [CAP-230: the C++ expression dialect](CAP-230.md), [CAP-100: six languages' expression dialects](CAP-100.md), [CAP-036: complete kinds for Python, TypeScript and C and C++](CAP-036.md), [CAP-093: every construct of C's and C++'s standards](CAP-093.md), [CAP-091: Ccpp expressions bridged to C and C++ source](CAP-091.md).

## Design

Not built. `C` is a complete dialect by [CAP-226: complete expression dialects](CAP-226.md)'s rules: every expression
of C11, C17 and C23 (ISO/IEC 9899, 6.5), one dialect each kind of which records as data the standards that have it,
held by `C`'s own `Expression`; printed, and checked against its grammar's node list. It is separate from
[CAP-230: the C++ expression dialect](CAP-230.md), since C++ is not a superset of C; together they replace today's Ccpp
dialect ([CAP-100: six languages' expression dialects](CAP-100.md)). Its kinds are mbse-programs' Ccpp expression kinds
that C has ([CAP-036: complete kinds for Python, TypeScript and C and C++](CAP-036.md)). Reading C's every construct is
[CAP-093: every construct of C's and C++'s standards](CAP-093.md)'s, and a bridge to C source
[CAP-091: Ccpp expressions bridged to C and C++ source](CAP-091.md)'s.

The gap, as [the proposal's survey](../../../mbse-expressions/docs/proposals/dialects/GAPS.md#c11-c17-c23) counts it: 9 kinds here (Ccpp's 7 and the framework's
`variable` and `call`) against mbse-programs' 46 Ccpp expression kinds and their helpers. C's lacking here:
parenthesized expressions, `_Generic`, increment and decrement, compound literals, initializer lists and designators,
unary `&` and `*`, `sizeof` and `alignof`, casts to any type name, assignment and the comma, C23's `true`,
`false` and `nullptr`, literals' spellings, and the GNU extensions. It is the proposal's stage 5.
